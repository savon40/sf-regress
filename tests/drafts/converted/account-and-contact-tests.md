# Account and contact regression tests

All tests run as a sales rep. Use a new account called "Regress Draft Co" for each test.

## TC-01 New account gets the right type

1. Create the account with Type "Customer - Direct".
2. Check the account's Type is "Customer - Direct" and its Rating is blank.

## TC-02 Contact links to its account

1. Create the account.
2. Add a contact, Jane Tester, to the account.
3. Open the account record page and check the contact appears in the Contacts related list.
